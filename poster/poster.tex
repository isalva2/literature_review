      % The preeminent transportation planning task that informs the majority of research effort in the field is \textbf{scenario evaluation}, asking ``what if?'', and using those possibilities to predict future traffic and network states. Existing approaches such as agent-based modeling and graph-based machine learning techniques are either computationally burdensome or limited in scope, respectively.
      
      We propose \textbf{\textls{\textsc{Scenes}}}, the \textbf{S}cenario-\textbf{C}ontextualized \textbf{E}vent-driven \textbf{N}etwork \textbf{E}volution \textbf{S}imulator, a transformer-based generative model that creates semantically aware traffic state predictions given only a single natural language input. Leveraging synthetic data from POLARIS, Argonne's high-fidelity traffic simulator, the model is trained to recognize and \emph{generalize} over 2{,}000 POLARIS simulation runs seeded with disruption conditions of varying intensity. The model exhibits state-of-the-art performance capable of the following properties:
      \begin{itemize}
        \item Identify link locations, flow direction, and disruption severity 
        \item Network-wide predictions exhibiting propagation effects and toplogical/physical consistency
        \item Near instantaneous inference and results generation ($ < 0.6$s)
      \end{itemize}

      % \hspace*{1.5em} The \textbf{\textls{\textsc{Scenes}}} model represents a new class of \emph{Human Mobility Foundation Models}, data-driven surrogates with the potential to revolutionize the field. With \textbf{\textls{\textsc{Scenes}}}, students, researchers, and policymakers can now propose and explore traffic scenarios and their cascading effects at a speed and convenience previously thought impossible.

      \end{chbox}

      \begin{chbox}{Problem Statement}
        Given text description $d$, a \textit{lane reduction disruption}, and directed network graph $G=(V,A)$, predict the hourly volumes $\hat{\mathbf{X}}$ and affected links $p$:
        \[
          d \overset{\textit{G}}{\rightarrow}(\hat{\mathbf{X}}, p), \enspace \hat{\mathbf{X}}\in\mathbb{R}^{N\times T} \enspace p_i \approx \mathrm{P}(\mathrm{link}\, i \, \mathrm{affected}\,\vert\,d),
        \]
        for a graph of $N=1028$ edges for $T=24$-hour time steps. This problem is further exacerbated by the following constraints:
        \begin{enumerate}
          \item \textbf{Geospatial semantics:} the POLARIS \textit{Grid Network} was used and does not encode real-world geographic information.
          \item \textbf{Model run noise:} Disruption-affected links exhibit 2\% of total variance, necessitating a localized error measure.
        \end{enumerate}
        
      \end{chbox}

      \begin{chbox}[stretch]{Data Description}
        \textbf{Data Sources}
        \begin{itemize}
          \item \textbf{Scenarios:} 2{,}133 POLARIS \textit{Grid Network} simulations initialized with five disruption patterns: single link, bi-directional single link, intersection, corridor, and bi-directional.
          \item \textbf{Text:} A local LLM, \texttt{mimo-v2.6-9B}, used to write description labels for each \textit{Grid Network} scenario run.
          \item \textbf{Graph:} 11 link features (lanes, speed, capacity, length, class) and adjacency matrix.
          \item \textbf{Embedding:} Frozen \texttt{MiniLM-L6-v2} text encoder embeds text descriptions as contextual information.
        \end{itemize}

      \begin{chbox}[stretch]{Methodology}
        \textbf{Model Architecture}
        \begin{itemize}
          \item \textbf{Stage 1: Grounding:} Every link attends to the words of the description, so a link can find its own number in the sentence. The output is a probability $p_i$ for each link.
          \item \textbf{Stage 2: Regression} Takes the link features and the mask $\tilde m$ and predicts 24 hourly values per link.
          \item Fully trained model can interpret and predict natural language scenarios such as  ``5.5 KM of EW2 MAJOR Corridor 359-361 and 635-628 are disrupted in the AB direction''
        \end{itemize}

      \textbf{Training and Inference} \\
      During training, stage 2 receives 50\% true mask and 50\% $p$, teacher learning from clean masks and generalizing. During inference only the text available, so $\tilde m = p$ and plain 
 
      % \hspace*{1.5em}Each graph block applies a text-conditioned scale and shift (FiLM), attends to the words, and message passes volume information along the road graph:

      \textbf{Loss Function} \\
      Losses are weighted based on proximity to disruption location, with far-away cells contributing minimal simulation noise and affected links weighted $20\times$ more than 1-hop neighbors:
      \[
      \mathcal{L} = \underbrace{\textstyle\sum w_{r,i}\,(\hat y_{r,i} - y_{r,i})^2}_{\text{weighted volume error}} \, + \, \underbrace{0.1\mathrm{BCE}(p, m)}_{\text{which links are affected}}
      \]
      \textbf{Evaluation} \\
      \textit{Skill} is evaluated over the global average, affected links, and k-hop neighbors. For $\mathcal{A}$, affected links:
      \[
      \mathrm{skill}_{\mathcal{A}} = 1 - \frac{\sum_{\mathcal{A}} (\hat y - y)^2}{\sum_{\mathcal{A}} y^2}
      \]
      
      is 1 for a perfect model and 0 for the baseline. We also report the share of the truly affected links among the model's top-$k$ guesses.
